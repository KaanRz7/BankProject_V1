# 🏦 BankProject_V1

A simple banking system developed in **C++** using **Object-Oriented Programming (OOP)** principles.

This is my **first C++ OOP project**, developed to practice object-oriented programming, user interaction, project organization and menu-driven application design.

## 📸 Preview

### Main Menu

```text
---------------- Welcome to the Bank Menu ----------------
1. Create Account
5. Exit
----------------------------------------------------------


### Account Menu (After Creating an Account)

```text
---------------- Welcome to the Bank Menu ----------------
2. Deposit
3. Withdraw
4. Show Account Information
5. Exit
----------------------------------------------------------


## ✨ Features

- Create a bank account
- Deposit money
- Withdraw money
- Display account information
- Menu-driven interface
- Basic input validation
- Error handling for invalid user input

## 🛠️ Technologies Used

- C++
- Object-Oriented Programming (OOP)
- Visual Studio 2022

## 🚀 How to Run

1. Open the solution file (`.slnx`) with Visual Studio.
2. Build the project.
3. Run the application.
